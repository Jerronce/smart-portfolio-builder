# Smart Portfolio Builder

A polished portfolio generator for developers and designers. It turns a profile summary, skills, and project list into a clean portfolio preview.

## Features

- Profile summary builder
- Skills and project cards
- Live portfolio preview
- Export-ready layout concept
- Browser-only demo

## How to run

Open `index.html` in your browser.

## Tech stack

- HTML
- CSS
- JavaScript

## Portfolio value

This project demonstrates product design, form-to-preview UI, personal branding, and front-end state management.
